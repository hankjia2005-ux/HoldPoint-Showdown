# 《红蓝据点枪战》普通模式 V1.1 规则定稿

> 状态：作品集 Demo 的单一规则源（Single Source of Truth）  
> 适用范围：单机 2V2 垂直切片；玩家 + 蓝方 AI 对阵 2 名红方 AI  
> 目标：消除 V1.0 中死亡、掉落、复活、命数、保护罩和结算的歧义

## 1. 本局基础规则

- 队伍：蓝方 2 人、红方 2 人；单机 Demo 为 1 名玩家 + 3 名 AI。
- 正式时间轴：发育期 `00:00-03:00`，争夺期 `03:00-05:00`，终局 `05:00-12:00`。
- 正式胜利条件：终局中让对方全员永久出局，且己方至少一人未永久出局。
- 12:00 到时无论击杀、物资或存活数如何，一律平局，不设置隐藏加时或积分判胜。
- 同一帧双方最后一人同时永久出局时判平局。
- 友军伤害关闭；子弹仍会被友军身体阻挡，避免穿过队友攻击敌人。

## 2. 出生与基础状态

- 玩家必须出生在己方基地的出生环内，而不是基地入口外。
- 初始生命 `100`，初始护甲 `0`，护甲上限 `50`。
- 初始装备为绑定基础手枪：弹匣 `12`，备弹 `30`。
- 绑定手枪不可主动丢弃、不可形成死亡掉落，防止无限复制基础武器和弹药。
- 每次成功复活恢复 `100` 生命、`0` 护甲，并重置为基础手枪 `12/30`。
- 背包为 `12` 格；武器占 `3` 格，最多携带 2 把；弹药包、医疗包、护甲片各占 1 格。

## 3. 死亡与掉落

死亡发生的瞬间，以死亡位置为掉落点，并按以下顺序处理：

1. 记录死亡所属阶段。
2. 掉落除绑定手枪外的全部武器，并保留各自弹匣与备弹。
3. 掉落背包内全部弹药包、医疗包、护甲片。
4. 清空当前护甲；不掉落“护甲数值”，只掉落尚未使用的护甲片。
5. 将玩家立即移回己方出生环，进入不可移动、不可射击、不可被攻击的等待状态。
6. 根据阶段执行复活或永久出局。

补充规则：

- 同类消耗品以堆叠掉落；拾取者空间不足时允许部分拾取，剩余数量保留在地面。
- 死亡掉落物生成后有 `0.6` 秒拾取保护，防止碰撞帧内被原持有者自动回收。
- 死亡掉落物 `60` 秒无人拾取后消失，避免长局对象无限堆积。
- 手动丢枪保留当前弹药，有 `0.8` 秒拾取保护；手动丢弃不能丢掉最后一把绑定手枪。

## 4. 三阶段复活规则

### 阶段一：物资发育

- 死亡次数无限。
- 无玩法冷却；保留 `0.75` 秒淘汰表现时间后在基地恢复控制。
- 所有本次携带的非绑定装备和背包物资照常掉落，玩家需要重新搜集发展。
- 己方基地保护开启：己方在保护区内无敌，敌方无法进入，会被送回入口外。

### 阶段二：攻防争夺

- 死亡次数无限。
- 死亡后立即回到基地等待，`5` 秒后恢复控制。
- 非绑定装备和背包物资全部掉落。
- 基地保护永久关闭，敌人可进入、攻击并抢夺共享箱。

### 阶段三：终局决战

- 05:00 整为所有未永久出局玩家统一设置 `2` 条终局命数；阶段一、二死亡不扣终局命数。
- 若玩家正处于阶段二复活等待，进入终局时立即在基地复活，再获得 2 条命，避免跨阶段状态不公平。
- 每次死亡扣 1 条命：剩 1 条时等待 `5` 秒后复活；降到 0 时永久出局。
- 永久出局后不可移动、射击、拾取、操作箱子或被再次计分。
- 某队全员永久出局后进入结算，不继续接受伤害或物资交互。

## 5. 基地与保护罩

- 基地保护只在阶段一有效，03:00 整永久关闭。
- 保护区内的己方单位免疫来自区内外的全部伤害。
- 敌方碰到保护区边界时被送到该基地入口外，不允许利用跳跃、传送或复活点穿入。
- 保护罩关闭后不再重新开启，死亡复活也不提供额外出生无敌；阶段二/三依靠基地结构和复活等待保护。
- 保护罩必须同时有视觉变化、全局文字提示和玩法碰撞效果，不能只做透明模型。

## 6. 地图物资与刷新

- 地图刷新点在阶段一、二按当前 Demo 数值每 `22` 秒刷新一次。
- 05:00 后不再生成新物资；终局开始时已经存在于场上的物资仍可拾取。
- 自动拾取只在背包有空间时执行；堆叠掉落允许部分拾取。
- 地图固定刷新点用于作品集可控演示；商业版再替换为建筑区域权重随机。
- 通用弹药包在 Demo 内为所有枪械补充其配置的单次弹药量；分口径弹药留待后续版本。

## 7. 共享物资箱

- 己方可存取，敌方只能取出、不能存入。
- Demo 箱子当前存储弹药包、医疗包、护甲片；每类上限 `20`。
- 箱子满时存入失败且不扣玩家物资；玩家背包满时取出失败且不扣箱内库存。
- 敌方成功取出时触发红光、基地被抢文字提示；敌方进入基地范围触发入侵提示。
- 武器存入、武器抢夺属于下一次纵向迭代的 P1，未完成前 UI 必须明确写“消耗品箱”，不能让玩家误以为可存枪。

## 8. 战斗与物资数值

- 生命上限 `100`，护甲上限 `50`；护甲先于生命承伤。
- 医疗包恢复 `40` 生命，不溢出；满生命时不可消耗。
- 护甲片恢复 `30` 护甲，不溢出；满护甲时不可消耗。
- 弹药包为当前武器增加其配置中的 `AmmoPerPickup`，不填充弹匣。
- 使用消耗品为即时动作；Demo 暂不设置施法时间，但死亡、永久出局或结算后不可使用。
- 首版关闭爆头倍率；不同部位伤害系数等角色碰撞体拆分完成后再启用，避免“策划写了但模型不支持”。

## 9. AI 与单机队伍

- 蓝方：玩家 + 1 名蓝方 AI；红方：2 名红方 AI。
- AI 只选择仍可战斗的敌方目标，禁止攻击队友或永久出局目标。
- 当前迭代最低验收：巡逻、动态换目标、遮挡检测、战斗、死亡、阶段复活、终局出局和触发结算。
- 搜物资、存共享箱、治疗、阶段二突袭属于后续 AI 状态机迭代；在完成前不得在作品集说明中宣称已经实现。

## 10. 界面与显示设置

- Windows 首次启动默认无边框全屏；`F11` 或 `Alt+Enter` 在无边框全屏与可调整大小窗口之间切换。
- 窗口模式允许最大化；失去焦点时游戏继续运行，便于单机调试和录屏。
- 标准移动为 `W/A/S/D`，其中 `S` 固定为后退；`左 Ctrl` 切换下蹲，避免与 `C` 使用护甲片冲突。
- 鼠标移动控制镜头与准星射击方向；角色上半身和枪械朝向跟随镜头水平方向。
- 默认第三人称视距为 `9` 米，鼠标滚轮可在 `5.5-12` 米之间缩放；墙体遮挡时镜头自动拉近，离开遮挡后恢复玩家选择的距离。
- HUD 必须显示：当前阶段、距离下一阶段/结束的时间、双方未出局人数、玩家复活倒计时、终局剩余命数、比赛结果。
- 死亡等待时显示“已返回基地，X.X 秒后复活”，不能只让角色消失。
- 结算后显示胜利/失败/平局，并锁定移动、射击、拾取和箱子交互。

## 12. 本轮验收标准

- 首次启动可进入全屏，且能切回可最大化窗口。
- 玩家无论在哪死亡，都立即回到蓝方基地等待，并在正确时间恢复控制。
- 阶段一死亡后升级武器和全部背包物资留在死亡位置，复活只剩基础手枪。
- 03:00 保护罩关闭；05:00 显示 2 条命；第二次终局死亡永久出局。
- 单机阵容为 2V2，AI 不攻击队友。
- 红方或蓝方全员出局能够结算，12:00 能够平局。
- EditMode、PlayMode 与 Windows 成品冒烟全部通过，运行日志无游戏逻辑异常。
