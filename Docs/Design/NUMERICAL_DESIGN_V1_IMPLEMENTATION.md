# 数值方案 V1.0 落地说明

本轮以 `HoldPoint_数值方案_v1.0.xlsx` 与 `HoldPoint_数值配置表_v1.0.xlsx` 为策划输入，将战斗、移动、物资、AI 和对局节奏收敛到可验证的 Unity 配置资产。运行时不再依赖散落在组件 Inspector 中的魔数。

## 已落地的单一真相源

| 系统 | Unity 配置 | 关键结果 |
| --- | --- | --- |
| 全局战斗与物资 | `GameBalanceConfig` | 100 生命、40 护甲、1:1 抵伤、12 格背包、消耗品读条、共享箱容量、掉落保护与销毁时间 |
| 对局节奏 | `GameRuleConfig` | 2V2–5V5 独立三阶段时长、复活延迟、出生保护、终局两命 |
| 武器 | `WeaponConfig` | 伤害、射速、弹匣/备弹、换弹、射程衰减、散布、后坐力、半自动/全自动 |
| 移动与镜头 | `MovementProfile` | 走/跑/蹲速度、加减速、空中控制、跳跃、ADS 移速和镜头参数 |
| 物资投放 | `LootBudgetConfig` + `LootDirector` | 按参战人数计算整局预算，分阶段释放，终局投放金色空投 |
| AI | `AIProfile` | 反应时间、探测/追击距离、误差和命中率、搜集/存仓/偷家倾向 |

## V1.0 核心数值

- 默认 3V3：0–120 秒搜集、120–240 秒攻防、240–540 秒终局；到时平局。
- 复活：第一阶段 0.5 秒、第二阶段 4 秒；阶段三每人两命。出生保护分别为 1.5/2/2.5 秒，仅覆盖 3 米出生区，离开或开火立即取消。
- 命中倍率：头部 1.5、躯干 1.0、四肢 0.8；远距离伤害分段衰减至 0.82/0.65/0.35。
- 武器：白手枪 24×3/s、绿冲锋枪 12×8/s、蓝步枪 22×4.2/s、紫霰弹枪 11×8 弹丸×1.3/s；手枪/步枪/霰弹枪半自动，冲锋枪全自动。
- 医疗包恢复 40，静止读条 3 秒且受伤打断；护甲片恢复 20，读条 1.5 秒且移动速度受限。
- AI 普通难度：55 米发现、30 米追击、0.55 秒反应、10 米基准命中率 55%，物理射线命中而非视线内必中。

## 架构与玩法修复

- 死亡会掉落当前背包与可掉落武器，按阶段在己方多个出生点复活；终局第二次死亡才永久出局。
- AI 从只防御升级为“搜集 → 存共享箱 → 攻击/偷家”，能够拾取更高品质武器并遵守同一套弹药、伤害和射程规则。
- 共享箱支持武器、弹药、医疗包、护甲的真实存取和容量限制；敌方只可抢夺，不可存入。
- 角色移动使用加速/减速和空中控制，疾跑为长按，双击 S 或左 Ctrl 下蹲；第一/第三人称与缩放均受统一镜头配置约束。
- 使用医疗/护甲时禁止射击和换弹，避免读条与战斗状态相互穿透。
- 主菜单默认选中“开始普通模式”，鼠标、键盘和手柄都能直接进入游戏。

## 自动化质量门禁

每次改动至少运行以下三层验证：

1. EditMode：数值资产、阶段边界、背包/共享箱、护甲、武器美术批次数量和打包设置。
2. PlayMode：主菜单、鼠标瞄准、相机缩放、AI 侦测、死亡掉落、复活、终局淘汰、空投和结算。
3. 加速完整对局：真实启用红蓝 AI，在约 8 秒内走完三阶段，要求 AI 产生实际伤害、比赛结束、物资预算不超发、角色无 NaN/穿地。

本轮基线：EditMode 43/43、PlayMode 16/16 全部通过，Windows 独立包构建成功。
